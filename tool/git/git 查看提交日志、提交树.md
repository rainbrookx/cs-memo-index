# git 查看提交日志、提交树

## Git查看提交记录操作

查看日志信息命令：

`git log`

查看历史记录的简洁的版本命令：

`git log --oneline`

查看历史中什么时候出现了分支、合并（提交树）命令：

`git log --oneline --graph`

逆向显示所有日志命令：

`git log --reverse --oneline`

查找指定用户的提交日志可以使用命令：

`git log --author=XX`
