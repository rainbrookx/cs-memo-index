# git 学习资源、学习心得

【 **前言** 】git 在开发项目中（工作中），非常有用。在大学毕业前，一定要学会 git。

---

**入门**：[《【狂神说Java】Git最新教程通俗易懂》](https://www.bilibili.com/video/BV1FE411P7B3/)

**巩固、精进**：

[《Learn Git Branching》](https://learngitbranching.js.org/?locale=zh_CN)

[《Learn Git Branching》（中文版）](https://oschina.gitee.io/learn-git-branching/)

**精通**：[《Git官网-文档》](https://git-scm.com)

---

先看 **“狂神说Java”** 的视频，他的视频通俗易懂、语言幽默，视频囊括 git 的常用操作，可以作为入门的资源。有一定基础后，学习 **“Learn Git Branching”** ，这是一个小游戏，挺有意思的。最后，如果想精通 git，那当然需要看 **git 的官方文档** 。

用 git 命令实际操作 git 仓库，是一个好的学习方法。
