## FYS 笔记

- 可以把异或看作，按位不进位的加法，而且满足交换律、结合律
- a XOR a = 0，0 XOR a = a ==> 偶数个相同数异或的结果是 0
- 一个数字和自己做偶数次异或运算，结果为 0；一个数字和自己做奇数次异或运算，结果为 1
- int right_one = x & (\~x + 1);  // 获取整数 x 右边的第一个为 1 的位
- 使用异或，可以编写更加节省空间的双向链表，被称为是**异或双向链表（XOR linked list）**
- x + ((y - x) >> 1)，取 x 与 y 的中点值

$$
\frac{x+y}{2}，其中 (x+y) 可能溢出\\
x + \frac{y-x}{2}，这样不会溢出\\
x + ((y - x) >> 1)
$$
