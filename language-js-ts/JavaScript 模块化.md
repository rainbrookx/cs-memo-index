# JavaScript 模块化

- sea.js
- require.js：RequireJS
- CommonJS
- ES Modules（ESM，ECMAScript 模块）
- AMD（Asynchronous Module Definition，异步模块定义）
- UMD（Universal Module Definition，通用模块定义）：不是独立规范，而是一种兼容方案，可同时支持 CommonJS、AMD 和全局变量（非模块化环境）。
- SystemJS：一种模块化加载器，支持多种模块格式（ESM、CommonJS、AMD 等），主要用于浏览器中统一处理不同规范的模块。
