# Vue.js 命令

## Vue CLI

### 创建项目

```bash
vue ui      # 图形界面（网页）
vue create hello-world      # 命令行 “hello-world” 是项目名称
```

### 运行项目

```bash
npm run serve
```

## create-vue（vite）

### 创建项目（vite）

```bash
npm init vue@latest
```

### 运行项目（vite）

```bash
npm install     # 首次运行，安装服务器程序
npm run dev
```
