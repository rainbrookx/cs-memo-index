# CSS

## CSS 术语

- 优先级、权重
- `inherit`、`initial`、`unset`、`revert`
  - `inherit`（继承）：从父元素传递值
  - `initial`（初始）：重置为默认值（将 CSS 属性重置为 CSS 规范中指定的初始值）
  - `unset`（取消设置）：全面重置（它结合了 `inherit` 和 `initial` 关键字的功能）
  - `revert`（恢复）：回归至浏览器样式
