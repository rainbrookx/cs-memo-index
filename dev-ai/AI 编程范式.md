# AI 编程范式

| 范式                | 核心关系                | 人做什么         | AI 做什么                   | 最佳规模      |
| ------------------- | ----------------------- | ---------------- | --------------------------- | ------------- |
| Vibe Coding         | 人说感觉，AI 生成       | 描述需求、看效果 | 全量生成代码                | 小 / 原型     |
| Agentic Engineering | 人定目标，AI 全流程     | 定目标、验收     | 拆需求 + 设计 + 编码 + 测试 | 中 / 大       |
| Harness Engineering | 人定规则，AI 受控执行   | 设计架构 + 规范  | 在约束下编码                | 大 / 企业级   |
| Ralph Wiggum Loop   | 人丢错误，AI 反复修     | 运行、贴报错     | 反复修复直到通过            | 小 / 脚本     |
| BMAD                | 多 AI 角色化敏捷协作    | 统筹、验收       | 分角色协同开发              | 中 / 团队     |
| SDD                 | 人写规范，AI 按规范编码 | 写 Spec、评审    | 严格按 Spec 实现            | 大 / 核心系统 |
