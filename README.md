## 说明

“我不生产知识，我只是知识的搬运工”，很多知识的资源，我 **通过链接提供**。如果链接失效，建议大家先通过我的笔记、URL 信息，在网上搜索。

搬运知识，而非写技术博客，是因为写技术博客太累了、太耗时间，而且在重新发明轮子，最关键的是我写的技术博客内容不全面、质量一般。

> **不要重新发明轮子（Stop Trying to Reinvent the Wheel）**

是程序员的一句行话，意思呢，是说业界已经有公认的软件或者库了，就不要自己从头再做啦。但是，这种现象却从来没有停止过，否则也不会有这句行话啦。（来源：网络）
