# 单片机

> 微控制单元(Microcontroller Unit；MCU) ，又称单片微型计算机(Single Chip Microcomputer )或者单片机

[国芯论坛](https://www.stcaimcu.com/)

[STC 芯片手册 | STC: 32位 8051 单片 | 深圳国芯](https://www.stcai.com/xpsc)

[Electronic Components Datasheet Search](https://www.alldatasheet.com/)

---

- 关键词：datasheet
- 单片机组成：CPU、数据存储器（RAM、SFR、XRAM）、程序存储器
- 哈佛结构：数据与程序分开存储的结构
- 冯诺依曼结构：由五个部分组成，运算器 Arithmetic Logic Unit、控制器 Control Unit、存储器 Control Unit、输入设备 Input Devices、输出设备 Output Devices
- 单片机是哈佛结构
- 接口与总线
- 单片机最小系统：单片机、系统电源、时钟电路、复位电路、下载电路
- 集成电路（IC）的封装形式
- 输出方式（端口）：推挽方式、上拉电阻方式、开漏方式
- BSP（板级支持包）

## 通信

- 串口通信：COM 口、UART 口, TTL、RS-232、RS-485
- 串口通信采用 LSB （低位优先）
- 单工、半双工、全双工

## 工具

- 数字万用表：推荐使用 `DT830B`
- 示波器：`优利德 UTD2102CEX`
- 下载器

- 实验板、万用板、洞洞板
