# 模拟电路

- PN结
- P型半导体：空穴
- N型半导体：自由电子
- 死区电压：硅管约0.5~0.7V，锗管约0.1~0.3V
- 击穿电压：雪崩击穿、齐纳击穿
- 有源器件、无源器件

## 整流方法

- 二极管半波整流
- 二极管半波整流 + 电容滤波
- 桥式全波整流电路

## LED

- LED 一般使用工作电流大小表示，而不使用工作电压
- 贴片 LED 工作电流 2~5mA、直插 LED 5~10mA

## 三极管

- 类型：NPN型、PNP型
- 3种状态：放大、截止、饱和
- 作用：电流放大元件、开关（截止、饱和）
- 最常使用 NPN型，NPN和PNP工作的极性相反

## 场效应管

场效应管是一种电压控制电流的器件，作用同三极管
