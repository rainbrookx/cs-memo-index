# Java 工具库

## 综合工具、有意思的工具

- `Hutool`
- `lombok`
- `Google Guava`
- `commons-lang3`
- `Apache Commons`

## 数据库

- 数据库连接池：C3P0、DBCP、Druid（阿里巴巴）、Hikari
- `Apache Commons DbUtils`
- `Mycat 2`：<http://www.mycat.org.cn/>
- [Java ORM 哪家强？10个ORM框架测试对比与选型建议](https://segmentfault.com/a/1190000044870584)
- `PageHelper`：MyBatis 数据库查询分页插件

## 深拷贝

[对象拷贝之Apache BeanUtils、Spring的BeanUtils、Mapstruct、BeanCopier、PropertieyUtils对比（深拷贝）](https://blog.csdn.net/ZYC88888/article/details/109681423)

## IO流、输入、输出

- `commons-io`：输入输出框架

## HTTP

- `Google HTTP Client Library For Java`：HTTP 协议的网络编程，包含了 JSON 的处理
- `Apache HttpClient`：
- `GWT(Google Web Toolkit)`
- [Java HTTP Client](https://openjdk.org/groups/net/httpclient/)
- `OkHttpClient`
- `Spring Boot WebClient`

## HTML、XML、JSON 解析

- `Jsoup`：HTML 解析
- `dom4j`：XML 解析
- `XPath`：获得 XML DOM 节点路径（org.jaxen）
- `Gson`：JSON 解析
- `Fastjson`：比 `Gson` 更简单

## Excel

- `EasyExcel`
- `Apache POI`

## 时间、日期

- `Joda-Time`

## Java 与其他编程语言交互

- `Jython`：Java 调用 Python

## 测试

- `JUnit`：`JUnit4` 和 `JUnit5` 不太一样（不兼容）
- `Hamcrest`：断言工具

## 日志

- `LogBack`：实现`slf4j-api`接口规范的日志框架
- `slf4j-api`：规范接口，Simple Logging Facade for Java

## 线程

- 线程池：Hippo4j

## GUI

- `Swing`：Java 自带的
- `JavaFX`
- `JFormDesigner`：其中 `FlatLaf` 是 Swing 风格，比较常用

## 图表制作

- `XChart`：制作的图表优美、易用
- `JFreeChart`：个人觉得没有 `XChart` 好看，好像要搭配 `JCommon`。<https://www.jfree.org/> 官网还提供了，`JFreeSVG` 和 `FXGraphics2D` 等，这还是比较有意思

## 视频、音频

- `VLC`：VLC 播放器提供的播放工具

## 安全

- `Apache Shiro`
- `Sa-Token`

## 其他

- CGLIB(Code Generation Library)
- GraalVM
- Java Chromium Embedded Framework (JCEF)
