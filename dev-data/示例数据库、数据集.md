```txt
除了Kaggle，还有许多其他平台提供丰富的数据集资源，涵盖不同领域和应用场景。以下是一些主要的公开数据集平台推荐：
国际知名平台

Google Dataset Search  

  提供全球公开数据集的搜索引擎，支持多种格式和领域。
UCI Machine Learning Repository  

  加州大学欧文分校维护的经典机器学习数据集，适合学术研究。
AWS Public Datasets  

  亚马逊云平台提供的大规模数据集，涵盖科学、医疗等领域。
Data.gov  

  美国政府开放数据平台，包含农业、气候等公共数据。
国内平台

阿里天池  

  阿里巴巴的数据竞赛平台，提供金融、交通等行业数据集。
DataFountain  

  中国数据科学竞赛平台，专为中文用户设计。
国家统计局数据平台  

  中国官方统计数据，涵盖经济、人口等领域。
行业专用平台

World Bank Open Data  

  全球经济与社会发展数据。
NASA Earth Science  

  地球科学与气候数据集。
OpenStreetMap  

  开源地理空间数据。
其他资源

GitHub数据集仓库  

  如Awesome Public Datasets，汇总多领域开源数据。
Papers with Code  

  结合前沿论文的数据集，适合AI研究。

如需特定领域的数据集（如医疗、金融），可进一步说明需求。
```
