# \[Error\] ld returned 1 exit status  报错常见情况

1. 编译时，之前运行的程序没有关闭
2. 没有 main 函数
3. 多个 main 函数
4. main 函数的英文单词拼写错误，相当于【没有 main 函数】
5. 调用函数，但没定义函数
6. 库函数拼写错误，如：printf，scanf，相当于【调用函数，但没定义函数】
7. 项目有多个源文件（\*.c 或 \*.cpp）时，在多个源文件中，都定义了**相同的全局变量**
8. 在头文件（\*.h）中，定义了变量（全局变量），此时，如果“项目有多个源文件（\*.c 或 \*.cpp），导入该头文件”，那么相当于【在多个源文件中，都定义了相同的全局变量】
