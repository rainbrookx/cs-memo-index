# JavaScript 语法

## async 和 await

- The async keyword gives you a simpler way to work with asynchronous promise-based code. Adding async at the start of a function makes it an async function. This enables you to write code that uses asynchronous functions but looks like synchronous code. [How to use promises - async and await](https://developer.mozilla.org/en-US/docs/Learn/JavaScript/Asynchronous/Promises#async_and_await)

- await is only valid in `async functions` and `the top level bodies of modules`
