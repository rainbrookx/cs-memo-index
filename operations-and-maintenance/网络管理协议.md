# 网络管理协议

| 协议               | 端口    | 用途             | 特点                            |
| ------------------ | ------- | ---------------- | ------------------------------- |
| **SNMP**           | 161/162 | 监控、告警、配置 | 标准化、跨厂商、主要用于监控    |
| **CLI**            | 22/23   | 配置、排错       | 最强大、最灵活、命令行界面      |
| **NETCONF**        | 830     | 配置管理         | 现代化、API驱动、支持配置回滚   |
| **RESTCONF**       | 443     | 配置管理         | RESTful API、JSON/XML、易于集成 |
| **SSH/Telnet**     | 22/23   | CLI访问          | 远程命令行访问                  |
| **HTTP/HTTPS**     | 80/443  | Web管理          | 图形界面、直观易用              |
| **Syslog**         | 514     | 日志收集         | 设备日志集中管理                |
| **TACACS+/RADIUS** | 49/1812 | 认证授权         | 集中式用户管理                  |
