# dotnet 命令

## 使用旧程序样式

```bash
dotnet new console --use-program-main
```

## 使用新的程序样式（默认）

```bash
dotnet new console
```

## 构建、运行

```bash
dotnet build
dotnet run
```

## 使用“发布”生成配置

```bash
dotnet run --configuration Release
```

## 发布应用

<https://learn.microsoft.com/zh-cn/dotnet/core/tutorials/publishing-with-visual-studio-code?pivots=dotnet-7-0>

```bash
dotnet publish --configuration Release
```
